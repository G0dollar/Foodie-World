Tools & acknowledgements

  • Built using HTML5, CSS3 and vanilla JavaScript.
  • AI-assisted code and content preparation using ChatGPT, with permission for AI use reported by the project author.
  • Local SVG assets were created for this project. Dish cards and region profiles now use real photographs credited below.
  • Recipe notes are simplified educational summaries. Regional associations are illustrative; many dishes have shared histories.

How the website works

Eighteen category pages cover six food regions. Search and vegetarian filters operate on the food cards. Surprise Me selects a visible result. Expandable recipe details use native HTML. The suggestion form validates input and stores it locally on the current browser.

No account, database or backend is required. No form data is transmitted.
