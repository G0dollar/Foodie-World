# Foodie World — implementation scope

## 1. Core pages

Home (1), six food regions with Drinks, Breakies and Fullies (18), and Credits (1): 20 pages. Regions: Asia, Europe, Africa, Americas, Middle East, Oceania. Each food page includes listings, random selection, vegetarian filtering and name search.

## 2. Recipe structure

Option A selected: inline expandable details, using native HTML details/summary. No additional dish-detail pages.

## 3. Required form

A separate Suggest a Dish page with JavaScript validation brings the required total to 21 pages. Suggestions are stored only in the browser; no backend is claimed.

## 4. Optional stretch features

Implemented after the core build: Compare Cuisines, Guess the Cuisine quiz, Gallery and unit converter. Four additional pages bring the site to 25 HTML documents.

## 5. Visual direction

Simple college-project layout: warm background, terracotta accent, shared header/footer, region cards and a readable food grid. Locally bundled real photographs fill dish cards and twelve-photo region collages; per-image credits preserve source and licence information. All pages use plain HTML, CSS and JavaScript.
