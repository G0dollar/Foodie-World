# Food photography source register

Most photographs are stored locally. The newly added menu entries link to Wikimedia thumbnails when rate limiting prevented a local copy. Native CSS grids arrange the region collages; no raster composite has been created. Each photograph retains its individual licence. Thumbnails are generated by Wikimedia or source hosts. Display cropping is performed using CSS; the lightbox shows the full frame where a local or full-size source is available.
